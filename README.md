# Near-term Quantum Computing (UvA, 2026-2027)

Course material for the MSc course *Near-term Quantum Computing* at the University of
Amsterdam.

- **Lecture notes:** <https://stefanopolla.github.io/ntqc/>, with a PDF download. One
  chapter per lecture, added as the course goes on. Sources in [`notes/`](notes/).
- **Tutorials:** Jupyter notebooks in [`tutorials/`](tutorials/). Each can be opened in
  Google Colab from the lecture notes (About page, tutorial table).

Author: Stefano Polla.
